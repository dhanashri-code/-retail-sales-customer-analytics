# Retail Sales & Customer Analytics
**Portfolio case study | Python (pandas) + MySQL + dashboard design**

## Transparency
This project uses **5,000 simulated order-line records** from 2024–2025. It is not real company data. All results below are calculated from the included CSV.

## Verified dataset results
- Sales: **$1,195,389.57**
- Profit: **$387,899.96**
- Order-line records: **5,000**
- Distinct customer IDs: **798**
- Average sales per record: **$239.08**
- Profit margin: **32.45%**

## Business questions
What are the headline sales/profit KPIs? Which categories, regions and customer segments contribute most? How do sales and profit move month by month? Which products lead by sales?

## Files
- `data/raw/` and `data/cleaned/`: CSV data
- `notebooks/`: reproducible Jupyter Notebook
- `sql/`: MySQL schema and analysis queries
- `outputs/`: grouped analysis tables
- `dashboard/`: static dashboard preview
- `docs/`: report and interview notes

## Power BI status
The PNG is a static dashboard preview, **not** an interactive Power BI `.pbix`. No PBIX is included. Import the cleaned CSV in Power BI Desktop to build an interactive report later.

## Resume wording — use after reviewing and understanding the work
**Retail Sales & Customer Analytics | Python, SQL, MySQL**
- Analysed 5,000 simulated retail order-line records using pandas and SQL to assess sales, profit, category, regional and customer-segment performance.
- Wrote reusable MySQL queries for KPI reporting, monthly trends, category and regional comparisons, and top-product analysis.
- Prepared a static executive dashboard preview and documented findings, metric definitions and dataset limitations.

## Limitations
The data is synthetic and cannot support claims about real customer behaviour or actual company performance. Discount comparisons are descriptive, not causal. This project is a portfolio practice case study, not employment experience.
